# secretcv-mcp 🇹🇷

mcp-name: io.github.mohammad-abbasi-sh/secretcv-mcp

سرور MCP غیررسمی و **فقط‌خواندنی** برای secretcv.com — سایت کاریابی ترکیه: جست‌وجوی شغل با کلیدواژه/شهر (حدود ۱۸٬۰۰۰ آگهی فعال)، جزئیات کامل هر آگهی از داده‌های schema.org JobPosting (عنوان، شرکت، شهر، تاریخ انتشار، نوع همکاری، حقوق در صورت اعلام، توضیحات + شرایط)، فهرست بخش‌ها و فهرست شهرها.

> ساختهٔ محمد عباسی در چارچوب «کارخانهٔ MCP ترکیه» (خط لوله به سبک سپهر). وابسته به secretcv.com نیست.

## برای ایجنت‌های هوش مصنوعی

به پیکربندی کلاینت MCP خود اضافه کنید (stdio):

```json
{
  "mcpServers": {
    "secretcv": {
      "command": "uvx",
      "args": ["secretcv-mcp==0.1.0"]
    }
  }
}
```

یا به‌صورت محلی اجرا کنید: `python -m secretcv_mcp.server` (نیازمند `mcp<2` و `curl-cffi`).

## ابزارها

| ابزار | توضیح |
|------|-------------|
| `secretcv_search_jobs` | جست‌وجوی شغل با کلیدواژه و/یا شهر — `query` («barista»، «garson»، «şoför»)، `city` («İstanbul»، «Ankara»، «İzmir»؛ «İstanbul Anadolu» و «İstanbul Avrupa» منطقه‌های جدا هستند)؛ تعداد کل آگهی‌های مطابق + آگهی‌ها (عنوان، شرکت، شهر، محله، تاریخ نسبی انتشار، URL آگهی). فقط صفحهٔ اول نتایج (۲۰ آگهی) |
| `secretcv_latest_jobs` | جدیدترین آگهی‌های secretcv.com (`limit` ۱ تا ۲۰)؛ تعداد کل آگهی‌های فعال + آگهی‌ها |
| `secretcv_get_job` | جزئیات کامل یک آگهی — `job_url` (همان URL که ابزارهای جست‌وجو/جدیدترین برمی‌گردانند)؛ عنوان، شرکت (+ URL صفحهٔ شرکت)، شهر/منطقه، تاریخ انتشار، نوع همکاری، حقوق ماهانه به لیر در صورت اعلام، توضیحات کامل + شرایط |
| `secretcv_list_sectors` | بخش‌های شغلی (مثل «Bankacılık / Finans»، «Bilgisayar / BT / İnternet»، «Çağrı Merkezi») با slug و URL فهرست؛ `limit` ۱ تا ۵۰ |
| `secretcv_list_cities` | شهرها/منطقه‌های ترکیه با آگهی (۸۱ استان؛ استانبول به Anadolu/Avrupa تقسیم شده) با slug و URL فهرست؛ `limit` ۱ تا ۵۰ |

## نحوهٔ کار

secretcv.com آگهی‌ها را کاملاً سمت سرور رندر می‌کند — بدون ورود، کلید API و کوکی. جست‌وجوی کلیدواژه مبتنی بر مسیر است (`/is-ilanlari/<kelime>-is-ilanlari`، مثلاً barista → ۲۲۰ آگهی)؛ فهرست شهر `/is-ilanlari/<şehir>-is-ilanlari` (استانبول → ۲٬۳۹۷ آگهی)؛ شهر + کلیدواژه `/is-ilanlari/<şehir>/<kelime>-is-ilanlari`. (فرم `?q=` کار نمی‌کند — HTTP 410.) هر صفحهٔ فهرست ۲۰ کارت شغلی (عنوان، شرکت، شهر + محله، تاریخ نسبی انتشار) و تعداد کل («18.225 İş İlanı Listelendi») دارد. صفحهٔ جزئیات آگهی یک بلوک JobPosting از نوع JSON-LD دارد (عنوان، توضیحات شامل «Genel Yetkinlikler» + «İŞ TANIMI»، شرایط، تاریخ انتشار، نوع همکاری، شرکت، مکان، حقوق — در صورت عدم اعلام «-»). فهرست بخش‌ها (`/sektore-gore-is-ilanlari`) بخش‌ها را با پیوندهای شهر/محله مخلوط می‌کند، پس تجزیه با مجموعهٔ slugهای ۸۱ استان فیلتر می‌شود. نام شهرها slug می‌شوند (İstanbul → istanbul). انتقال با جعل TLS کروم انجام می‌شود (`curl-cffi`، `chrome120`)؛ درخواست‌ها با فاصلهٔ ~۰٫۸ ثانیه؛ همه‌چیز فقط‌خواندنی است.

## نصب

```bash
uvx secretcv-mcp==0.1.0        # اجرای مستقیم (نیازمند uv)
# یا
pip install secretcv-mcp==0.1.0
secretcv-mcp    # سرور MCP را روی stdio راه می‌اندازد
```

## تست‌ها

```bash
python -m venv .venv && .venv/bin/pip install -e .
.venv/bin/python -m unittest discover -s tests -v
```

تست‌های آفلاین روی صفحات واقعیِ ضبط‌شده اجرا می‌شوند (دریافت‌شده در ۲۰۲۶-۱۱-۰۷)؛ تست‌های زنده به secretcv.com وصل می‌شوند. در زمان ساخت ۲۵/۲۵ سبز (۱۶ آفلاین + ۹ زنده) + تست دود MCP روی stdio.

## نقشهٔ راه

- صفحهٔ دوم فهرست‌ها (سایت پیوند صفحه‌بندی سمت سرور ندارد؛ به API «بارگذاری بیشتر» نیاز است)
- صفحات شرکت (`/firma/<slug>-is-ilanlari`: همهٔ آگهی‌های یک کارفرما)
- آمار حقوق به‌ازای کلیدواژه/شهر (بیشتر آگهی‌ها حقوق اعلام نمی‌کنند)
